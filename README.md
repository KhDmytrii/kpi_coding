Цей проект реалізує шифрування файлів у вказаній директорії.

Як зібрати проект

1. Склонуйте репозиторій або завантажте файли.
2. Відкрийте термінал і перейдіть до директорії проекту.
3. Виконайте команду "make", щоб зібрати проект.

Як запустити проект
1. Підготуйте директорію з файлами, які потрібно зашифрувати. Створіть папку, наприклад to_encrypt, у кореневій директорії проекту та помістіть у неї файли, які потрібно зашифрувати.
2. Запустіть скрипт encryptor.sh, передавши шлях до директорії.

./encryptor.sh /path_to_directory/to_encrypt

Після виконання скрипта будуть створені дві нові директорії:

to_encrypt_encrypted/ — міститиме зашифровані файли.
to_encrypt_keys/ — міститиме файли з випадковими ключами для кожного зашифрованого файлу.

Вивід програми mixer записується у файл random_bytes.txt.
