# Encryptor

Цей проект реалізує шифрування файлів у вказаній директорії.

## Як зібрати проект

1. Склонуйте репозиторій або завантажте файли.
2. Відкрийте термінал і перейдіть до директорії проекту.
3. Виконайте команду "make", щоб зібрати проект.

## Як запустити проект
1. Підготуйте директорію з файлами, які потрібно зашифрувати.
2. Запустіть скрипт encryptor.sh, передавши йому шлях до директорії.

./encryptor.sh to_encrypt

Це створить нову директорію to_encrypt_encrypted, в якій будуть зашифровані файли, а також файл random_key.txt з випадковим ключем, який використовується для шифрування.
